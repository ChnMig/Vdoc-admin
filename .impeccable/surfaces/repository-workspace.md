# Document workspace

Mode: Operate and Read. Preserve the established Control Plane tokens and the approved Yuque-like document layout.

## Direction contract

**THESIS:** A project organizes documents. Every document owns independent branches and numbered history. Workflow changes must preserve the document reading layout.

**OWN-WORLD:** Existing neutral surfaces, navy actions, compact typography, document tree and shared controls.

**STORY:** Select a document, read its selected branch/version, edit and save a new numbered version, then inspect history or compare. Share only after explicit publication.

**FIRST VIEWPORT:** Left project document tree; central reader up to 52rem; right outline at 15rem and vertical tools at 3rem. Header actions are Share, Edit and reading utilities. Branch/version selection and New branch remain above the content. No horizontal task tabs. Mobile uses a file sheet, tool menu and the same right-side tool surface over the reader.

**FORM:** Use the stable document shell as the visual baseline. Every document tool opens in the right sidebar: outline at 15rem; AI, history, compare, merges, releases and subscriptions at 24rem. Expanding changes the same panel width to cover the reader leftward, with a 220ms eased transition and reduced-motion support. No native dialog close/show or subtree remount occurs on expansion. AI defaults to continuous document chat and retains version analysis as a separate mode; legacy sessions, attachments, reasoning, streaming and retries remain available. Keep reader, editor and visited tool state through tool changes. History remains scoped to the selected document and branch. Group subscription events by versions/branches, review/merge, publication and AI, using localized action labels and explanations. A sole leading H1 is an article title in the outline; skipped heading levels do not create phantom nesting.

**FINISH:** Verify desktop and mobile reading, outline navigation, retained scroll/input, AI resizing/focus, branch/version independence, publication/share permissions, keyboard access and no overflow. Retain screenshots and test evidence with the release. No new raster assets.
